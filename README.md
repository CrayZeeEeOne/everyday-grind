# Everyday Grind

Щоденне змагання в Wordle, Globle, Angledle, Minecraftle, Krillion, Plain, Chainle та Contexto.

```
Сайт (Netlify)  ⇄  Google Apps Script  ⇄  Google Sheet (дані та формули)
```

## Крок 1. Таблиця та скрипт (близько 5 хвилин)

1. Відкрийте [sheets.new](https://sheets.new) і назвіть таблицю, наприклад, `Everyday Grind`.
2. У меню таблиці: **Extensions → Apps Script** (Розширення → Apps Script).
3. Видаліть усе у файлі `Code.gs`, вставте вміст [`apps-script/Code.gs`](apps-script/Code.gs) і натисніть 💾.
4. Угорі оберіть функцію **`setup`** і натисніть **Run**.
5. Google попросить дозвіл. Оберіть свій акаунт. Якщо з’явиться «Google hasn’t verified this app», натисніть **Advanced → Go to … (unsafe)**. Це попередження показують для будь-якого власного скрипта. Скрипт просить доступ до таблиць і до запуску за розкладом.
6. У таблиці з’являться вкладки `Players`, `Config`, `Results`, `Log`, `Daily`, `Monthly`, `Champions`.
7. У редакторі скрипта: **Deploy → New deployment**, біля «Select type» ⚙️ → **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
8. Натисніть **Deploy** і скопіюйте **Web app URL** (закінчується на `/exec`).

> ⚠️ Захисту немає (як і домовлялися): хто знає цю адресу або адресу сайту, той може змінювати дані. Тому не додавайте її в код: репозиторій публічний.

## Крок 3. Netlify

1. [app.netlify.com](https://app.netlify.com) → **Add new project → Import an existing project → GitHub** → оберіть репозиторій.
2. Налаштування збірки Netlify візьме з `netlify.toml`, змінювати нічого не треба.
3. Додайте змінну середовища **`API_URL`** зі значенням адреси з кроку 1.8 (на екрані імпорту або пізніше в налаштуваннях проєкту, розділ Environment variables).
4. **Deploy**. Якщо змінну додали після першого деплою: **Deploys → Trigger deploy**.
5. Бажану назву (`everyday-grind.netlify.app`, якщо вільна) задайте в налаштуваннях проєкту (Change project name).

Якщо на сайті видно жовтий напис «Демо-режим», то `API_URL` не підставився.

Надалі кожен `git push` оновлює сайт автоматично.

## Перевірка після запуску

1. Відкрийте сайт і додайте всіх гравців у вікні «Хто ви?».
2. Внесіть по одному результату в **кожну** гру, щоб перевірити формули. Бал на картці рахує саме таблиця.
3. Виправте один результат і перевірте сторінку «Журнал».
4. Гляньте вкладки `Daily` та `Monthly` у таблиці.
5. Видаліть тестові результати кнопкою «Видалити».

## Як рахуються бали

Кожна гра дає 0–100 балів, день і місяць — це суми. Не зіграв або не пройшов: 0.

| Гра | Формула |
|---|---|
| Wordle, Angledle | 1→100, 2→90, 3→75, 4→55, 5→35, 6→15 |
| Minecraftle | 100 за 1 спробу, далі −10 за кожну |
| Globle | логарифмічна: 1 спроба→100, 100 і більше→0 |
| Contexto | логарифмічна: 1→100, 1000 і більше→0; −10 за кожну підказку |
| Krillion / Plain / Chainle | очки від максимуму 700 / 1000 / 5000 |

Переможець дня — найбільша сума (при рівності перемагають обоє).
Чемпіон місяця — найбільша сума за місяць, при рівності вирішує кількість перемог у днях.

## Чемпіон місяця

Скрипт фіксує його **1-го числа приблизно о 00:05 за Києвом** (Google допускає відхилення на кілька хвилин).
Якщо потім із сайту додати, виправити чи видалити результат за минулий місяць, чемпіон **перерахується автоматично**,
а зміна власника титулу з’явиться в «Журналі». Лише після ручних правок прямо в таблиці скористайтеся меню
**Everyday Grind → Перерахувати чемпіона минулого місяця** (з’являється після перезавантаження таблиці).

## Налаштування без коду

- **Новий гравець:** кнопка з іменем угорі сайту → «Новий гравець».
- **Прибрати гравця зі списку:** вкладка `Players`, `active` = `FALSE`. Його історія залишиться.
- **Підкрутити бали чи вимкнути гру:** вкладка `Config` (`max`, `best`, `hintPenalty`, `table`, `active`).
  Увага: зміна перераховує й **минулі** результати. Зафіксований чемпіон місяця перерахується, лише коли зміниться якийсь результат того місяця.
- **Нова гра:** новий рядок у `Config`. `type`: `table` (бали за номер спроби), `log` (менше = краще) або `linear` (більше = краще).

## Оновлення скрипта

Після зміни `Code.gs`: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
Адреса не зміниться. Звичайний «New deployment» створив би нову.
